## 01 — Problem

Most personal sites are either a résumé PDF wearing HTML, or a bloated CMS you stop updating within a month.

## 02 — Thesis

Static-by-design: Astro + Markdown + GitHub Actions + GitHub Pages. Every project, essay, and art piece is a file in this repo. Push to `main`, the archive grows.

## 03 — Architecture

Content Collections define the schema for projects, history, writing, art, and lab experiments. No admin panel — the repo is the admin panel.
